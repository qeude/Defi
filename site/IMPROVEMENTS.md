# Landing-page revision

The page targets Mac users and developers arriving from GitHub and communities.
The primary action is copying the Homebrew command. No analytics baseline was
available; the expected effects below are hypotheses.

| Change | Reason |
| --- | --- |
| Replace the hero recording with an interactive preview | Visitors try the shortcuts themselves before installing. |
| Group features in a bento of illustrations and real clips | Several features fit in one screen, each with a picture of what it does. |
| Show Defi's real cheatsheet for the shortcuts | The keys are the product; the panel users will see shows how few there are. |
| Fold first-launch steps into the FAQ | The hero and closing section keep one action each. |
