Your desktop,
without the edges.

Defi is a scrolling window manager for macOS: windows line up side by side on one strip, and the keyboard takes you along it.

With curl

With the DMG. Download it from the latest release and drag Defi to Applications. macOS blocks its first launch: open Defi, close the warning, click Open Anyway in System Settings › Privacy & Security, and confirm.

Defi is self-signed and not notarized, so only install it if you trust this source.
