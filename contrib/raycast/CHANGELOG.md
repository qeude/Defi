# Defi Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search Windows: focus any managed window, bring it to the current workspace, move it, float it, or copy its title.
- Search Workspaces: jump to a workspace on any display, or move the focused window or column there.
- Run Command: run any Defi command; the search text sets widths and targets workspaces.
